#  Záhada Temného lesa

Záhada Temného lesa je jednoduchá textová dobrodružná hra vytvořená v Pythonu.

##  O hře
Hráč se ocitne v tajemném lese, ze kterého se snaží dostat ven. Během cesty musí dělat různá rozhodnutí, řešit matematické příklady a překonávat nebezpečné překážky.

Každé rozhodnutí může ovlivnit pokračování příběhu. Cílem je přežít a najít cestu z lesa.

## ⚙️ Funkce hry
- Rozhodování pomocí čísel 1 a 2
- Matematické souboje s nepřáteli
- Náhodně generované příklady
- Jednoduchý inventář
- Různé cesty, výhry a konce hry
- Kontrola správného zadávání odpovědí

## 🚀 Jak spustit hru
1. Nainstaluj si Python 3.
2. Stáhni soubor `zahada_temneho_lesa.py`.
3. Spusť ho pomocí příkazu:

```bash
python zahada_temneho_lesa.py
```

## 🛠️ Použité technologie
- Python 3
- Knihovna `random`

Hra vznikla jako začátečnický projekt pro procvičení programování v Pythonu, zejména podmínek, cyklů, funkcí a práce s uživatelským vstupem.
